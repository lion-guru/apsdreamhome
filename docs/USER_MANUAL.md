## Getting Started

### System Requirements
- **Web:** Modern browser (Chrome, Firefox, Safari, Edge)
- **Mobile:** Android 8+ or iOS 13+
- **Internet:** Required for real-time features

### Login Instructions
1. Navigate to `http://localhost/apsdreamhome/`
2. Click "Login" in the top right
3. Select your role (Admin, Associate, Agent, Customer)
4. Enter your email and password
5. Click "Sign In"

## Troubleshooting

### Common Issues

#### Login Issues
- **Forgot Password:** Use "Forgot Password" link
- **Account Locked:** Wait 15 minutes after 5 failed attempts
- **Session Expired:** Login again

#### Performance Issues
- **Slow Loading:** Clear browser cache
- **Timeout:** Check internet connection
- **500 Error:** Contact administrator

#### Mobile App Issues
- **App Crashing:** Clear app cache and restart
- **Login Failed:** Check credentials
- **Sync Issues:** Pull to refresh
