## 🎯 **SYSTEM OVERVIEW**

### Three Lead Sources:
1. **Self Generated** (Associate ki khud ki mehnat)
2. **Company Provided** (Telecaller/Office/Data Purchase)
3. **Referral Network** (Upline/Downline se aaye)

### Commission Structure Based on Source:

| Lead Source | Commission % | Reason |
|-------------|--------------|--------|
| **Self Generated** | 100% (Full) | Apna kaam, pura commission |
| **Company Provided** | 60-70% | Company ne diya, thoda kam |
| **Referral (Upline)** | 80% | Upline ne diya, respect mein thoda kam |

## 💰 **COMMISSION STRUCTURE DETAILED**

### **Tier 1: Self Generated Leads (100% Commission)**

```
Associate ne khud lead banayi:
┌────────────────────────────────────────┐
│  Example: Plot Sold = ₹10,00,000      │
│                                        │
│  Commission Calculation:               │
│  ├─ Rank: Associate (5%)               │
│  ├─ Commission = ₹10,00,000 × 5%       │
│  ├─ Final = ₹50,000                   │
│  └─ Associate gets: ₹50,000 (100%)     │
│                                        │
│  Differential to Upline:               │
│  ├─ Sr. Associate (7%) - 5% = 2%     │
│  ├─ BDM (10%) - 7% = 3%                │
│  └─ ... upto 7 levels                  │
└────────────────────────────────────────┘
```

### **Tier 2: Company Provided Leads (60% Commission)**

```
Company ne lead diya:
┌────────────────────────────────────────┐
│  Example: Plot Sold = ₹10,00,000      │
│                                        │
│  Commission Calculation:               │
│  ├─ Normal Commission = ₹50,000 (5%)  │
│  ├─ Company Lead Deduction = 40%       │
│  ├─ Associate gets: ₹50,000 × 60%      │
│  └─ Final = ₹30,000                   │
│                                        │
│  Company gets: ₹20,000                │
│  (For lead generation cost recovery)   │
└────────────────────────────────────────┘
```

## 💡 **MY RECOMMENDATION**

### **Best Approach:**

1. **Google Login** - Sabse easy, sabko aata hai
2. **Referral Code Optional** - Customer ko force mat karo, incentive do
3. **Incentive for Using Code:**
   - "Use Referral Code REF123 and get ₹5,000 discount!"
   - Ya: "Get free site visit worth ₹2,000"
   - Ya: "Priority booking advantage"

4. **Lead Source Tracking:**
   - Self Lead: Green tag (100% commission)
   - Company Lead: Orange tag (60% commission)
   - Telecaller Lead: Blue tag (70% commission)

5. **Fair System:**
   - Jisne mehnat ki hai, usko commission mile
   - Company ko bhi kuch mile (cost recovery)
   - Customer ko benefit mile (discount)
   - Sab khush rahein!
